# XiaoDroidLink Privacy Policy

Last updated: 2026-10-05

XiaoDroidLink connects an Android phone to a compatible Xiaomi YU7 CarLink screen. The app is an independent project and is not an official Xiaomi, Samsung, Google, Android Auto, or ICCOA product.

## Data collection

XiaoDroidLink is designed to process driving and phone integration data locally on the device. The app does not sell personal data.

The app may process the following data on the phone when the user enables the related feature:

- Bluetooth and nearby device information, used to find and connect to the car.
- Location, used for Bluetooth/Wi-Fi discovery requirements, local map features, weather, road safety, and trip context.
- Screen capture, used only after Android shows the system screen-capture prompt and the user grants permission. It is used to show the selected map app or phone screen on the car display.
- Notification content, used only after the user grants notification access. It is used to show media status, navigation directions, and selected messenger status on the car dashboard.
- Microphone/audio capture, used only for optional audio features through CarLink.
- Accessibility events and gestures, used only after the user enables the XiaoDroidLink accessibility service. This is used to forward touch input from the car screen to the phone and to keep the phone usable while connected to the car.
- App list and app icons, used to let the user choose which apps appear in the car dashboard.

## Network use

XiaoDroidLink may connect to online map, weather, and road-safety data sources when those features are enabled. These requests are used to provide the requested in-car dashboard features.

## Permissions

XiaoDroidLink requests Android permissions only for the features shown in the app:

- Bluetooth and nearby device permissions: car discovery and connection.
- Location: Android Bluetooth/Wi-Fi requirements and optional map/safety features.
- Notification access: media, navigation, and messenger dashboard integration.
- Accessibility: touch forwarding from the car screen to the phone.
- Screen capture / MediaProjection: phone screen and selected map app display in the car.
- Microphone: optional audio through CarLink.
- Foreground service: keeping the active car connection running during a drive.
- Ignore battery optimizations: reducing unexpected disconnections while the app is actively connected.

## User control

The user can disable optional permissions at any time in Android system settings. Disabling a permission may disable the related feature.

## Data sharing

XiaoDroidLink does not sell user data. The app does not intentionally share notification content, screen content, or accessibility data with third parties. Some optional online features may send ordinary network requests to the relevant service provider to retrieve map, weather, or road-safety information.
