XiaoDroidLink Android ტელეფონს CarLink-ით Xiaomi YU7-ის ეკრანს უკავშირებს: პანელი საათით, ამინდით, მუსიკით, რუკითა და შეტყობინებებით, ტელეფონის ეკრანი მანქანაში შეხებით მართვით, ნავიგაცია და მანქანის ასისტენტი თქვენს ენაზე.

**მუშაობს CarLink-ის (ICCOA) მქონე მანქანებთან.** მომხმარებლებმა უკვე დაადასტურეს მუშაობა Xiaomi (YU7, SU7), Toyota (RAV4), Nissan (X-Trail T32), Haval (Xiaolong Max), Deepal (S05), GAC (Aion Y Plus), Wuling (Starlight 730), Lynk & Co (08) და Jetta (VS8) მანქანებზე. სხვა მანქანა CarLink-ით? სცადეთ და გამოგზავნეთ ანგარიში აპიდან — მოვაგვარებთ.

ეს დამოუკიდებელი აპია და არ არის Xiaomi-ის, Samsung-ის, ICCOA-ის, Android Auto-ს ან Google-ის ოფიციალური პროდუქტი.

## ინსტალაცია

XiaoDroidLink არის Google Play-ში: [https://play.google.com/store/apps/details?id=salon.lifestyle.xiaodroidlink](https://play.google.com/store/apps/details?id=salon.lifestyle.xiaodroidlink). განახლებები თავად მოდის. საჭიროა Android 13 ან უფრო ახალი.

## პირველი დაკავშირება

1. გახსენით CarLink მანქანის ეკრანზე.
2. გახსენით XiaoDroidLink, შეეხეთ „დაკავშირებას“, შეიყვანეთ 6-ნიშნა კოდი მანქანის ეკრანიდან და დაუშვით მანქანის Wi‑Fi.
3. „ნებართვებში“ დაუშვით ყველაფერი საჭირო. შემდეგ ტელეფონი თავად დაუკავშირდება, როცა მანქანაში ჩაჯდებით.

## XiaoDroidLink-ის ხმოვანი ბრძანებები — ნებისმიერ მანქანაში

- 🎤 რუკის ვიჯეტზე: თქვით მისამართი და მარშრუტი დაიწყება.
- 🎤 მუსიკის ბარათზე: თქვით სიმღერა ან შემსრულებელი და მუსიკა ჩაირთვება.

## მანქანის ასისტენტი თქვენს ენაზე

**მხოლოდ Xiaomi-ს მანქანებისთვის.** სხვა მანქანებში საჭის ღილაკი რთავს მანქანის საკუთარ ასისტენტს; რა ბრძანებებს ესმის, მოდელზეა დამოკიდებული.

ჩართვა: პარამეტრები → „მანქანის ასისტენტი თქვენს ენაზე“. დააჭირეთ ასისტენტის ღილაკს საჭეზე, თქვით ბრძანება (მაგ. „საბარგულის გახსნა“) და ტელეფონი მას მანქანას ჩინურად ეტყვის. ბრძანებების სია: პარამეტრები → „ასისტენტის ბრძანებები“ (ტელეფონზე და მანქანაში). ქართული ბრძანებები ნათარგმნია, მაგრამ მანქანაში ჯერ არ შემოწმებულა — თუ რომელიმე არ მუშაობს, მოგვწერეთ.
