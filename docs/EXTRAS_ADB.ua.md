# Додаткові функції через комп'ютер

Один раз підключаєте телефон до комп'ютера кабелем, запускаєте наш помічник — і XiaoDroidLink отримує дві можливості, яких Android звичайним застосункам не дає:

| Що | Без помічника | З помічником |
|---|---|---|
| Ви заблокували телефон кнопкою | музика в машині замовкає, машина перепідключається | **музика грає далі, з'єднання не рветься** |
| Запит «Дозволити трансляцію» | при кожному підключенні | **ніколи** |
| Телефон лежить під час поїздки | тьмяний | **майже чорний** (у руці — звичайний) |
| Android зупинив службу керування («Сервис работает некорректно») | треба вимкнути й увімкнути вручну | **перезапускається сама** |

Без помічника XiaoDroidLink теж працює — це лише покращення. Усе можна вимкнути тим самим помічником.

Потрібно: комп'ютер (Windows, Mac або Linux), USB-кабель, XiaoDroidLink **8.26 або новіший**. Займе 5 хвилин.

---

## Крок 1. Увімкніть на телефоні «Налагодження по USB»

Це робиться один раз.

**Samsung**
1. Налаштування → **Відомості про телефон** → **Відомості про ПЗ**.
2. **7 разів** натисніть **«Номер збірки»**. Може попросити PIN-код телефона. З'явиться «Режим розробника ввімкнено».
3. Поверніться в Налаштування → в самому низу **«Параметри розробника»**.
4. Увімкніть **«Налагодження USB»**.

**Xiaomi, Redmi, POCO**
1. Налаштування → **Про телефон**.
2. **7 разів** натисніть **«Версія ОС»** (або «Версія MIUI»).
3. Налаштування → **Додаткові налаштування** → **Для розробників**.
4. Увімкніть **«Налагодження по USB»**.
5. Тепер з'явиться пункт **«Налагодження по USB (налаштування безпеки)»**. Він вимагає два речі:
   - **вхід у Mi-акаунт**: Налаштування → **Mi-акаунт** (або Xiaomi-акаунт) → увійдіть;
   - **SIM-картку** в телефоні.
   Коли обидві умови виконано, знову відкрийте «Для розробників» і увімкніть **«Налагодження по USB (налаштування безпеки)»**. Телефон попросить підтвердження — натисніть «Так».
6. Вимкніть кабель, підключіть знову і на телефоні натисніть **«Дозволити»**.
   Якщо пункт «(налаштування безпеки)» сірий — перевірте обидві умови з пункту 5.
   **Чому помічник пише «зроблено частково»:** без цього пункту Xiaomi не дає видати дозвіл для затемнення й перезапуску служби. Акаунт потрібен **на телефоні**, акаунт машини не потрібен.

**Інші телефони** (Honor, vivo, OnePlus, Pixel, Motorola…)
1. Налаштування → **Про телефон** → **7 разів** натисніть **«Номер збірки»**.
2. Налаштування → **Система** → **Для розробників** (або пошук у налаштуваннях: «розробник»).
3. Увімкніть **«Налагодження по USB»**.

## Крок 2. Скачайте помічник

**[⬇ XiaoDroidLink-Helper.zip](https://github.com/vvkovtun/xiaodroidlink-releases/raw/main/helper/XiaoDroidLink-Helper.zip)**

**Розпакуйте** архів (правою кнопкою → «Видобути все» / подвійне натискання на Mac). Усередині три файли — потрібен лише той, що для вашого комп'ютера.

## Крок 3. Підключіть телефон кабелем і запустіть

**Windows**
- Двічі натисніть **`XiaoDroidLink-Helper-Windows.bat`**.
- Якщо з'явилося синє вікно «Windows захистила ваш ПК» → **«Докладніше»** → **«Однаково запустити»**.

**Mac**
- Натисніть **`XiaoDroidLink-Helper-Mac.command`** **правою кнопкою** (або з Control) → **«Відкрити»** → ще раз **«Відкрити»**.
- Якщо Mac пише, що не може відкрити: Системні параметри → **Конфіденційність і безпека** → внизу **«Усе одно відкрити»**.

**Linux**
- Відкрийте термінал у папці з файлом і введіть: `bash XiaoDroidLink-Helper-Linux.sh`

Помічник сам скачає з сайту Google потрібні інструменти Android (близько 7 МБ) — встановлювати нічого не треба.

## Крок 4. Відповідайте помічнику

1. Виберіть мову: **3** і Enter.
2. На телефоні з'явиться вікно **«Дозволити налагодження по USB?»** → позначте **«Завжди дозволяти»** → **«Дозволити»**.
3. Помічник напише «Телефон знайдено» і покаже меню. Введіть **1** і Enter.
4. Побачите **«Готово ✓»**. Від'єднайте кабель — усе.

---

## Як вимкнути

Запустіть помічник так само і виберіть:
- **2** — вимкнути все й повернути як було;
- **3** — лише прибрати затемнення екрана.

Затемнення можна вимкнути й без комп'ютера: опустіть шторку телефона → кнопка **«Додаткове затемнення»**.

## Якщо щось не виходить

| Помічник пише | Що зробити |
|---|---|
| «Телефон не видно» | Інший кабель (деякі лише заряджають). Перевірте, що «Налагодження по USB» ввімкнено. На телефоні виберіть для USB «Передавання файлів». |
| «Телефон не видно» лише на Windows | Windows потрібен драйвер телефона. Samsung: встановіть «Samsung USB Driver» із сайту samsung.com. Інші: зазвичай ставиться сам — зачекайте хвилину після підключення. |
| Вікно «Дозволити налагодження» не з'являється | Від'єднайте й знову під'єднайте кабель, розблокуйте телефон. |
| «XiaoDroidLink застарів» | Оновіть XiaoDroidLink у Google Play і запустіть помічник ще раз. |
| «Зроблено частково» на Xiaomi / Redmi / POCO | Не ввімкнено «Налагодження по USB (налаштування безпеки)». Увійдіть у Mi-акаунт, вставте SIM-картку, увімкніть пункт (крок 1, пункти 5–6) і запустіть помічник ще раз. |
| «Не вийшло» | Надішліть текст із вікна помічника через «Щось не працює? Надіслати звіт» у застосунку. |

Дозволи зберігаються після оновлень XiaoDroidLink і зникають лише після його видалення.
