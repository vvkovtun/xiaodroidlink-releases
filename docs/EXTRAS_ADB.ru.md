# Дополнительные функции через компьютер

Один раз подключаете телефон к компьютеру кабелем, запускаете наш помощник — и XiaoDroidLink получает две возможности, которых Android обычным приложениям не даёт:

| Что | Без помощника | С помощником |
|---|---|---|
| Вы заблокировали телефон кнопкой | музыка в машине замолкает, машина переподключается | **музыка играет дальше, связь не рвётся** |
| Запрос «Разрешить трансляцию» | при каждом подключении | **никогда** |
| Телефон лежит во время поездки | тусклый | **почти чёрный** (в руке — обычный) |
| Android остановил службу управления («Сервис работает некорректно») | нужно выключить и включить вручную | **перезапускается сама** |

Без помощника XiaoDroidLink тоже работает — это только улучшения. Всё можно выключить тем же помощником.

Нужно: компьютер (Windows, Mac или Linux), USB-кабель, XiaoDroidLink **8.26 или новее**. Займёт 5 минут.

---

## Шаг 1. Включите на телефоне «Отладку по USB»

Это делается один раз.

**Samsung**
1. Настройки → **Сведения о телефоне** → **Сведения о ПО**.
2. **7 раз** нажмите **«Номер сборки»**. Может попросить PIN-код телефона. Появится «Режим разработчика включён».
3. Вернитесь в Настройки → в самом низу **«Параметры разработчика»**.
4. Включите **«Отладка по USB»**.

**Xiaomi, Redmi, POCO**
1. Настройки → **О телефоне**.
2. **7 раз** нажмите **«Версия ОС»** (или «Версия MIUI»).
3. Настройки → **Расширенные настройки** → **Для разработчиков**.
4. Включите **«Отладка по USB»**.
5. Теперь появится пункт **«Отладка по USB (настройки безопасности)»**. Он требует две вещи:
   - **вход в Mi-аккаунт**: Настройки → **Mi-аккаунт** (или Xiaomi-аккаунт) → войдите;
   - **SIM-карту** в телефоне.
   Когда оба условия выполнены, снова откройте «Для разработчиков» и включите **«Отладка по USB (настройки безопасности)»**. Телефон попросит подтверждение — нажмите «Да».
6. Отключите кабель, подключите снова и на телефоне нажмите **«Разрешить»**.
   Если пункт «(настройки безопасности)» серый — проверьте оба условия из пункта 5.
   **Почему помощник пишет «сделано частично»:** без этого пункта Xiaomi не даёт выдать разрешение на затемнение и перезапуск службы. Аккаунт нужен **на телефоне**, аккаунт машины не нужен.

**Другие телефоны** (Honor, vivo, OnePlus, Pixel, Motorola…)
1. Настройки → **О телефоне** → **7 раз** нажмите **«Номер сборки»**.
2. Настройки → **Система** → **Для разработчиков** (или поиск в настройках: «разработчик»).
3. Включите **«Отладка по USB»**.

## Шаг 2. Скачайте помощник

**[⬇ XiaoDroidLink-Helper.zip](https://github.com/vvkovtun/xiaodroidlink-releases/raw/main/helper/XiaoDroidLink-Helper.zip)**

**Распакуйте** архив (правой кнопкой → «Извлечь всё» / двойной щелчок на Mac). Внутри три файла — нужен только тот, что для вашего компьютера.

## Шаг 3. Подключите телефон кабелем и запустите

**Windows**
- Дважды щёлкните **`XiaoDroidLink-Helper-Windows.bat`**.
- Если появилось синее окно «Windows защитила ваш компьютер» → **«Подробнее»** → **«Выполнить в любом случае»**.

**Mac**
- Щёлкните **`XiaoDroidLink-Helper-Mac.command`** **правой кнопкой** (или с Control) → **«Открыть»** → ещё раз **«Открыть»**.
- Если Mac пишет, что не может открыть: Системные настройки → **Конфиденциальность и безопасность** → внизу **«Всё равно открыть»**.

**Linux**
- Откройте терминал в папке с файлом и введите: `bash XiaoDroidLink-Helper-Linux.sh`

Помощник сам скачает с сайта Google нужные инструменты Android (около 7 МБ) — устанавливать ничего не нужно.

## Шаг 4. Отвечайте помощнику

1. Выберите язык: **2** и Enter.
2. На телефоне появится окно **«Разрешить отладку по USB?»** → отметьте **«Всегда разрешать»** → **«Разрешить»**.
3. Помощник напишет «Телефон найден» и покажет меню. Введите **1** и Enter.
4. Увидите **«Готово ✓»**. Отключите кабель — всё.

---

## Как выключить

Запустите помощник так же и выберите:
- **2** — выключить всё и вернуть как было;
- **3** — только убрать затемнение экрана.

Затемнение можно выключить и без компьютера: опустите шторку телефона → кнопка **«Дополнительное затемнение»**.

## Если что-то не получается

| Помощник пишет | Что сделать |
|---|---|
| «Телефон не виден» | Другой кабель (некоторые только заряжают). Проверьте, что «Отладка по USB» включена. На телефоне выберите для USB «Передача файлов». |
| «Телефон не виден» только на Windows | Windows нужен драйвер телефона. Samsung: установите «Samsung USB Driver» с сайта samsung.com. Другие: обычно ставится сам — подождите минуту после подключения. |
| Окно «Разрешить отладку» не появляется | Отключите и снова подключите кабель, разблокируйте телефон. |
| «XiaoDroidLink устарел» | Обновите XiaoDroidLink в Google Play и запустите помощник ещё раз. |
| «Сделано частично» на Xiaomi / Redmi / POCO | Не включена «Отладка по USB (настройки безопасности)». Войдите в Mi-аккаунт, вставьте SIM-карту, включите пункт (шаг 1, пункты 5–6) и запустите помощник ещё раз. |
| «Не получилось» | Пришлите текст из окна помощника через «Что-то не работает? Отправить отчёт» в приложении. |

Разрешения сохраняются после обновлений XiaoDroidLink и пропадают только после его удаления.
